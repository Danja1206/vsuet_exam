# Современные технологии разработки ПО

## Задание: 
- закоммитить и запушить в ветку GIT локального репо файл remote.md, содержащий команды для записи в удаленный репо

## Команды для записи в удаленный репозиторий

Добавить удаленный репозиторий

```sh
git remote add origin {ссылка}
```
> Например:
```sh
git remote add origin https://github.com/Danja1206/vsuet_exam.git
```

Посмотреть текущий подключенный репозиторий

```sh
git remote -v
```

Отправить ветку в удаленный репозиторий

```sh
git push -u origin {название ветки}
```

> Например:
```sh
git push -u origin GIT
```
