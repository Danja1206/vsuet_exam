Ответ: ENTRYPOINT не установлен.

Задание 3. Какая ENTRYPOINT установлена для создания образа реляционной базы данных, коммюнити версии mysql?
Выполнение:
cat Dockerfile-mariadb
Ответ: ENTRYPOINT ["docker-entrypoint.sh"]

Задание 4. Какая CMD установлена для создания образа системы управления контентом wordpress?
Выполнение:
cat Dockerfile-wordpress
Ответ: CMD ["apache2-foreground"]

Задание 5. Какой будет окончательная команда при запуске контейнера из образа wordpress из данного Dockerfile? Прими во внимание и инструкцию ENTRYPOINT, и инструкцию CMD
Выполнение:
cat Dockerfile-wordpress
Ответ: docker-entrypoint.sh apache2-foreground

Задание 6. Какая команда выполняется при запуске контейнера, созданного из Dockerfile с названием ubuntu?
Выполнение:
cat Dockerfile-ubuntu
Ответ: CMD ["bash"]
